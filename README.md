# SoundFusion — Music Website

**English**

SoundFusion is a music website built with PHP, MySQL, HTML, and CSS. It features an artist catalog and dynamically generated artist pages.

### Features
- Artist catalog
- Dynamic artist pages
- MySQL database integration
- Responsive website styling

### Technologies
PHP · MySQL · HTML · CSS

## Русский

SoundFusion — музыкальный веб-сайт, разработанный с использованием PHP, MySQL, HTML и CSS. Проект включает каталог исполнителей и динамические страницы артистов.

### Возможности
- Каталог исполнителей
- Динамические страницы артистов
- Интеграция с базой данных MySQL
- Оформление сайта с помощью CSS

### Технологии
PHP · MySQL · HTML · CSS
